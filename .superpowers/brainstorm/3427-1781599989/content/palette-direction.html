Step 2 · Background Effects & Animations (multi-select)

These are component-level effects from React Bits, Aceternity UI, and custom shaders. Each can be applied to specific sections rather than globally.

Aurora
Aurora Background
React Bits · react-bits.dev
Animated radial blobs creating a soft gold/green light diffusion. Already partially in project as AuroraGold — needs intensity tuning.
Grain
Film Grain / Noise Texture
CSS + SVG Filter · no library
Subtle animated noise overlay on dark sections. Used by high-end fashion sites (Kenzo, Loewe) for tactile luxury depth. Zero performance cost.
Spotlight
Spotlight / Beam Effect
Aceternity UI · ui.aceternity.com
Mouse-tracked spotlight that follows cursor on hero sections. Creates a dramatic "jeweller's loupe" feel. Adds interactivity without distracting from content.
Button
Animated Gradient Border
React Bits / CSS only
Gold gradient that rotates around button/card borders. Draws the eye to CTAs. Use on primary action buttons for premium feel.
Particles
Floating Gold Particles
tsParticles / React Bits
Slow-drifting gold dust on hero/CTA sections. Very subtle. Evokes diamond dust. Pure CSS alternative possible for zero bundle cost.
Grid
Subtle Gold Grid / Dot Pattern
Aceternity UI / SVG pattern
Faint architectural grid or dot pattern for text-heavy sections. Like graph paper — adds structure and sophistication without competing with content.
